# DSH Windows 对话提醒 1.0.0
> Windows 版 DSH Desktop 在后台时，主对话结束后高亮任务栏按钮并发送静音系统通知。

这是本地安装包，不是 DeepSeek 官方插件。兼容范围为 **Windows 上的 DSH Desktop `0.2.2-rc.5`**；其他版本未验证。包名沿用 `@local/dsh-taskbar-test`，避免测试版和正式版分别出现。

## 安装与升级

1. 将 `.tgz` 保存到不会随意清理的本地目录，不要解压。也可以直接从本仓库工作副本安装；选择这个方式时，不要在卸载前移动工作副本。
2. 如果已装测试版，在 DSH 侧栏的「插件」中找到「任务栏与系统通知」，先卸载旧包 `@local/dsh-taskbar-test`。不需要删源文件或手改 DSH 配置。
3. 打开「插件 → 添加插件」，输入 `.tgz` 的完整路径，或本仓库工作副本的完整目录路径。安装后点「立即启用」，确认版本显示为 `1.0.0`。只有界面提示需要重启时才重启。

禁用或卸载可在同一插件页完成。若要回退并且仍保留旧源码目录，可在卸载正式包后用「添加插件」重新安装旧目录。

## 何时提醒

- DSH 处于后台时，用户主对话真正结束才提醒（正常完成或出错后不再继续）。子代理或工具结束、Goal 自动续跑的中间轮次、仅由定时任务触发的轮次、主动取消都不提醒。
- 后台有任务栏窗口时高亮按钮，切回 DSH 后结束提醒。Windows 决定它是闪烁还是持续高亮。不抢焦点，不改托盘图标。
- 同时向 Windows 提交静音通知。DSH 隐藏到托盘时没有可高亮的窗口按钮，但仍尝试发通知。DSH 在前台时不提醒。
- 通知标题和正文固定，不包含聊天内容、标题或文件名。插件不调用模型或访问网络，不修改注册表或应用安装包。
- 未加入等待回复、等待审批、跳转到指定对话或 macOS 支持。

## 验收与排查

1. **手动通道测试**：在聊天框的斜杠菜单中选 `/taskbar-test`，10 秒内切到别的应用。观察任务栏高亮和「DSH 提醒测试」静音通知。回来后运行 `/taskbar-test-status`，查看最近一次结果。两条命令都不调用模型。
2. **自动触发测试**：发送一条需要一点时间处理的普通消息，在回复结束前切到其他应用。结束后应收到「DSH 对话已结束」。再试一次，留在 DSH 前台，预期不提醒。
3. **高亮了但没弹横幅**：按 Win + N 检查通知中心，查看 Windows「系统 → 通知」中是否允许 DeepSeek Harness 通知，并检查勿扰模式。「已提交」表示已交给 Windows，不表示横幅一定弹出。

## 回归测试

在仓库根目录或解包后的 `package` 目录下，用 Windows 上的 Node.js 运行 `npm test`。测试不闪任务栏、不发通知；覆盖普通对话、排队输入、Goal 自动续跑、主动取消、定时轮次、子代理、并发完成与卸载清理。

可选：运行 `node check.mjs <DSH主进程PID> "<DSH可执行文件完整路径>"`，附加只读探测窗口归属和通知载荷。正常安装不需要运行测试；包不包含安装脚本和第三方依赖。

## 打包

在仓库根目录运行 `npm pack --offline --ignore-scripts` 生成 `.tgz`。安装包不是 Git 跟踪文件。
